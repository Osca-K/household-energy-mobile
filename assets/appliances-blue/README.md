# Blue appliance illustrations

Separate colour variants of the 23 existing appliance illustrations, edited using the built-in image generation tool. Original artwork remains in `../appliances`, and the initial transparent extractions remain in `../appliances-transparent`.

Each input was its matching transparent appliance PNG. The common prompt was:

> Use case: precise-object-edit. Edit target: Image 1, existing appliance illustration. Change ONLY its colour palette to pearl white with soft blue/periwinkle accents matching the user's vacuum reference: midtone #7093ED, lighter #BACBFF, deeper #4F70C6. Convert orange, purple, cyan or vivid electric blue accents to this restrained blue family. Preserve the exact appliance silhouette, details, scale, placement, white rounded tile, smooth material highlights and diffuse soft shadow. White body remains white. Keep the existing canvas dimensions and genuine transparent exterior; preserve partially transparent shadow edges. No opaque rectangular backdrop, no new objects, no text, no geometry changes. Return a separate transparent PNG. Target appliance asset: [filename stem].

These PNGs include their own rounded tile and shadow. Render with contain sizing on transparent surfaces without another decorative image wrapper.
